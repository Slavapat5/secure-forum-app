# Secure Commenting Web Application Demo

This project is a Flask + SQLite web application used to demonstrate:

Python Version: Python 3.14.0

- Insecure vs secure implementations
- SQL Injection
- XSS 
- Mitigations using secure coding practices
- Sensitive Data Exposure


## How to run locally

## 1. Create and activate virtual environment

    python -m venv venv
    venv\Scripts\activate

## 2. Install dependencies

    pip install -r requirements.txt

## 3. Initialize database

    python setup_db.py

## 4. Run the app

    python app.py

The Default URL Should Be: http://127.0.0.1:5000/
